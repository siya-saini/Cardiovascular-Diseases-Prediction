# Early Prediction of Cardiovascular Disease Using Machine Learning Algorithms

## Project Overview

This project uses machine learning classification algorithms to predict the likelihood of cardiovascular disease based on patient health and lifestyle features.

## Dataset

The dataset contains patient information, including age, gender, height, weight, blood pressure, cholesterol, glucose, smoking, alcohol consumption, and physical activity.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Machine Learning Algorithms

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Tree
* Support Vector Machine (SVM)

## Model Results

Test accuracies reported in the project:

| Algorithm           | Accuracy |
| ------------------- | -------: |
| Logistic Regression |   72.39% |
| KNN                 |   69.32% |
| Decision Tree       |   72.73% |
| SVM                 |   72.84% |

## Project Workflow

1. Data cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature selection
4. Train-test split
5. Model training and evaluation
6. Comparison of classification algorithms
